# VLA 4D Icon Pack

Android-проект: пак из 90 иконок (256x256) + приложение-каталог.

## Как получить APK (без Android Studio)
1. Создай на github.com новый репозиторий (можно приватный).
2. Загрузи в него ВСЁ содержимое этой папки (Add file -> Upload files, перетащи папки как есть,
   важно чтобы была папка `.github/workflows/build.yml`).
3. Вкладка Actions -> "Build APK" -> Run workflow. Через 3-5 минут внизу страницы запуска
   будет артефакт `VLA-4D-Icon-Pack-apk` — скачай, распакуй, там `app-debug.apk`.
4. Поставь APK на телефон (разреши установку из неизвестных источников).

## Как включить иконки
Nova Launcher -> Настройки Nova -> Вид и ощущение -> Тема иконок -> VLA 4D Icon Pack
(или кнопка "Применить в Nova Launcher" в самом приложении).

## Если у каких-то приложений иконка не подменилась
Открой приложение пака -> "Скопировать список моих приложений" -> пришли список в чат.
Иконки в паке уже есть, нужно только точное имя приложений для appfilter.xml.
